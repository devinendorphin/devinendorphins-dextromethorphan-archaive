# Probes

Generated by `analysis/probe.py`.

## Test A0 -- a metric that had to be thrown away

The obvious rejection measure is `removedFragments` carrying `origin: ai` -- text a later block deleted that the model had written. Pooled it gives a striking ~44%, near-identical across every model from 2021-era Euterpe to GLM-4.6. It is an artifact.

Across 1675 stories the value never once exceeds 0.5 (n>0.5: **0**), and **43%** of stories sit in the top sliver 0.45-0.50. A hard ceiling at exactly one half is a formula, not a behaviour.

The cause is visible in the block stream: NovelAI's editor implements a whole-document rewrite as *delete everything, re-insert everything*. The delete charges every prior AI character to `removedFragments`; the re-insert comes back stamped `origin: user`. So a story where the author merely pasted their text back in scores as ~50% 'rejected', and the measure saturates. It tracks the editor, not the author's judgement, which is why it looked identically flat across five years of models.

Everything below uses branch reachability instead: walk `prevBlock` back from `currentBlock` to get the surviving branch, and count AI text that is *not* on it. That is text the author generated and then rewound past.
